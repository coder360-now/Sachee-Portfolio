# Security policy

## Architecture

This portfolio is a static React site. It has no database, authentication, admin interface, contact-form backend, runtime API keys, or server-side data processing. Interactive demos run with mock logic in the visitor's browser.

## Reporting a security issue

Please do not publish exploitable details in a public issue. Use GitHub's private vulnerability reporting for this repository when it is available, or contact the repository owner through the email link on the portfolio.

## Repository safeguards

- Never commit passwords, tokens, private resume material, customer data, or confidential company information.
- Keep two-factor authentication enabled on the GitHub account.
- Protect the `main` branch and require the build check before merging.
- Review Dependabot updates and the dependency audit before deployment.
- Keep GitHub Pages HTTPS enforcement enabled.
